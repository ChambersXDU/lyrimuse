# 03. 封面链路

## 定位

封面链路负责读取当前曲目的图片、验证它属于当前曲目，并为悬浮歌词、菜单栏和其它 App 视图提供封面与强调色。歌词搜索得到的 `cover_url` 会随候选写入 Swift 缓存，封面读取和歌词匹配彼此独立。

## 获取与验证

- `LocalPlaybackSource` 在曲目变化时请求当前播放器封面；常规状态轮询不重复下载大图。
- `PlaybackCoordinator` 先使用系统 Now Playing 图片；图片过小或明显是视频横幅时，再通过 `EnrichCacheReader.albumMatchedCoverURL` 查缓存候选。
- 缓存查找优先精确匹配歌手、歌名和专辑，再做保守的大小写、空白和繁简归一化，避免同名不同版本串封面。
- 封面只在曲目 key 匹配时采用，切歌边界拿到上一首图片则丢弃。

## 颜色与展示

`PlaybackCoordinator` 从封面派生前景强调色，供悬浮歌词和菜单栏控件使用。没有封面或图片不合格时回到设置中的固定颜色和占位图；这不会影响歌词搜索或缓存。

## 数据

缓存中的 `cover_url` 由五源歌词候选提供，App 直接读写 `lyrimuse-enrich-cache.json`。静态封面原始数据只在需要时保留在内存，删除歌词条目会同时删除该条目的候选封面信息。
