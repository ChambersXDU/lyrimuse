# 14. 设置、配置与本地化

## 定位

设置页是 Swift App 的唯一配置入口。偏好、歌词来源、播放器选择、显示选项和快捷键由 App 直接读写，不需要等待其它服务重启。

## 主要设置

- 播放器选择、受信任播放器和 Apple Music 自动化权限。
- 歌词来源开关与顺序：LRCLIB、酷我、网易云、酷狗、QQ 音乐。
- 歌词显示：悬浮歌词、菜单栏歌词、译文、罗马音、时间轴偏移和外观。
- 歌词管理：缓存统计、歌词文件夹、重新扫描和手动匹配。
- 通用：开机启动、菜单栏/Dock 行为、快捷键和本地化。

## 存储

App 偏好使用现有 UserDefaults/config 文件；歌词缓存和歌词文件使用 `EnrichCacheStore` 的直接写入路径。配置备份仍由 `ConfigPortability` 处理，歌词正文和运行时缓存不会被重复合并。

开机启动使用 `SMAppService.mainApp`。开关只改变登录项状态，不启动、停止或重启歌词搜索进程。
