# 11. 歌词管理窗口

## 定位

歌词管理窗口读取 `EnrichCacheStore` 的条目，提供筛选、查看、编辑、删除、联网搜索和重新匹配。它与自动换歌共用 `LyricsSearchService`，不会启动额外进程。

## 常用操作

- 「联网搜索候选歌词」保留 Resolver 返回的候选列表，用户可以查看来源、时长、匹配项和附加字段后手动应用。
- 「重新自动匹配」重新查询五个启用源，使用 `LyricsMatcher` 的最佳结果并写回当前条目。
- 编辑、删除、人工标记和时间轴偏移直接写入 Swift 单进程缓存；写入后立即刷新当前播放和列表。
- 歌词文件夹中的 `.lrc`、`.tr.lrc`、`.roma.lrc` 和 `.yrc` 仍用于导出和人工编辑。

## 缓存与筛选

列表摘要由缓存条目生成，支持歌手、歌名、专辑、来源、歌词质量、更新时间和人工校准等现有筛选。正在搜索的当前曲目可以显示临时占位行，但不会伪造一条持久化缓存。

解析决策窗口继续展示候选评分、来源响应和共识信息。其数据来自本次 Swift Resolver 的搜索结果或缓存摘要，不依赖旧的进程间记录。
