# 10. 译文与罗马音

## 定位

译文和罗马音是 `LyricsCandidate` 的可选字段，随最佳候选一起缓存。缺少这些字段不会阻止原文歌词显示；悬浮歌词和菜单栏按现有设置决定是否显示副行。

## 来源

- 网易云、酷狗和 QQ 音乐可提供源自带译文或罗马音，Provider 在解析时填入对应字段。
- 酷狗 KRC、QQ QRC/YRC 的协议解码会同时保留可用的逐字数据和附加轨道。
- LRCLIB 主要提供原文 LRC；酷我按返回结果提供可用的原文及附加字段。
- App 侧 `Romanizer` 继续为适合的中、日、韩歌词提供展示端注音，不修改缓存正文。

## 展示与设置

歌词设置中的译文、罗马音开关仍然有效。缓存中没有译文或罗马音时，UI 只隐藏对应副行；人工编辑原文不会清除其它字段，重新搜索才会替换搜索结果。
